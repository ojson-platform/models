# cache-zip

## Purpose

Сжатие выключено, пока его не включат. Решает флаг стратегии, а если его нет — флаг по умолчанию. Включённое сжатие кладёт в хранилище текст: JSON значения, затем deflate, затем base64.

## Requirements

### Requirement: Сжатие включается вместе со стратегией

Пока ни стратегия, ни значение по умолчанию сжатие не включают, хранилище SHALL получать значение Model как есть.

Флаг стратегии важнее флага по умолчанию, в том числе когда стратегия оставляет сжатие выключенным, а по умолчанию оно включено.

#### Scenario: По умолчанию значение хранится как есть

- **WHEN** сжатие нигде не включено, и cache-first сохраняет результат
- **THEN** хранилище получает то значение, которое вернула Model

#### Scenario: Флаг стратегии включает сжатие

- **WHEN** cache-first включает сжатие и сохраняет результат
- **THEN** хранилище получает текст deflate в base64, а следующее чтение с тем же включённым сжатием возвращает исходное значение

#### Scenario: Выключенный флаг стратегии важнее включённого по умолчанию

- **WHEN** по умолчанию сжатие включено, а стратегия cache-first задаёт сжатие выключенным, и обращение сохраняет результат
- **THEN** хранилище получает значение Model как есть

### Requirement: Выбор сжатия остаётся в общей конфигурации

Включённый флаг SHALL записываться в общую конфигурацию. Следующая Model с той же стратегией и в той же конфигурации кэша получает его, даже если сама флаг не задаёт. Выбор, который задаёт только срок и не задаёт флаг, уже записанный флаг не снимает.

#### Scenario: Следующая Model наследует чужое сжатие

- **WHEN** по умолчанию сжатие выключено, одна Model со стратегией cache-first включает сжатие и сохраняет результат, а следующая Model с той же стратегией и в той же конфигурации кэша флаг не задаёт
- **THEN** хранилище получает результат второй Model текстом deflate в base64

### Requirement: Чтение следует флагу читающей стратегии

Флаг чтения SHALL быть флагом той стратегии, которая читает, а не отметкой на записи.

Если читающая стратегия сжатие выключила, она возвращает хранимый текст, а не исходное значение.

Если сжатие включено и текст раскрывается, вызывающий получает исходное значение. Если текст раскрыть нельзя, вызывающий получает этот текст. Если хранимое значение не текст, вызывающий получает его как есть.

Фоновое обновление пишет в той же форме, которую стратегия выбрала для сжатия.

#### Scenario: Чтение без сжатия не раскрывает запись

- **WHEN** значение сохранено со сжатием, сжатие по умолчанию выключено, а следующее обращение читает запись стратегией cache-only и своё сжатие не включает
- **THEN** вызывающий получает хранимый текст, а не исходное значение

#### Scenario: Нераскрываемый текст возвращается как есть

- **WHEN** в хранилище лежит текст, который не является deflate в base64, и читающая стратегия включила сжатие
- **THEN** вызывающий получает этот текст

#### Scenario: Не-текст при включённом сжатии возвращается как есть

- **WHEN** в хранилище лежит значение не в виде текста, и читающая стратегия включила сжатие
- **THEN** вызывающий получает это значение

#### Scenario: Фоновое обновление пишет в выбранной форме

- **WHEN** stale-while-revalidate включает сжатие, и попадание запускает фоновое обновление
- **THEN** запись обновления в хранилище — текст deflate в base64
