# network-only

## Purpose

Стратегия network-only всегда выполняет Model. Хранилище она не читает и не пишет.

## Requirements

### Requirement: Сохранённое значение не участвует в ответе

Обращение SHALL выполнить Model и вернуть её результат. Уже сохранённое значение не читается и не подменяет результат. Новая запись не создаётся.

#### Scenario: Повтор не берёт сохранённое значение

- **WHEN** значение Model уже лежит в хранилище, и другой запрос обращается к той же Model с теми же props со стратегией network-only
- **THEN** Model выполняется снова, вызывающий получает её новый результат, и хранилище не получает новую запись

#### Scenario: Первое обращение тоже не пишет

- **WHEN** записи ещё нет, и вызывающий обращается со стратегией network-only
- **THEN** Model выполняется, вызывающий получает её результат, и хранилище не получает запись
