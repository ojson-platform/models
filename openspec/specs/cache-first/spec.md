# cache-first

Стратегия cache-first при попадании возвращает сохранённое значение и Model не выполняет. При промахе выполняет Model и сохраняет результат, если к этому моменту кэш запроса ещё включён. Фоновое обновление она не запускает.

## Requirements

### Requirement: Попадание не выполняет Model и не пишет снова

Если значение уже есть, обращение возвращает его. Model не выполняется. Хранилище не получает новую запись.

#### Scenario: Другой запрос берёт сохранённое значение

- **WHEN** значение уже сохранено, и другой запрос обращается к той же Model с теми же props со стратегией cache-first
- **THEN** вызывающий получает сохранённое значение, Model не выполняется, и хранилище не получает новую запись

### Requirement: Промах выполняет Model и сохраняет результат

Если записи нет, Model выполняется. Вызывающий получает её результат, не дожидаясь записи в хранилище. Если кэш запроса к этому моменту включён, результат записывается. Ошибка записи до вызывающего не доходит.

Если Model завершается ошибкой, ошибка доходит до вызывающего, и запись не создаётся. Следующее обращение снова выполняет Model.

#### Scenario: Первое обращение сохраняет результат

- **WHEN** записи нет, и вызывающий обращается со стратегией cache-first
- **THEN** Model выполняется, вызывающий получает её результат, и хранилище получает этот результат

#### Scenario: Ошибка Model не сохраняется

- **WHEN** Model при промахе завершается ошибкой
- **THEN** вызывающий получает эту ошибку, хранилище не получает запись, и следующее обращение снова выполняет Model

#### Scenario: Ошибка записи не меняет ответ

- **WHEN** Model при промахе вернула результат, а запись в хранилище не удалась
- **THEN** вызывающий получает результат Model
