# cache-only

## Purpose

Стратегия cache-only возвращает сохранённое значение или ничего. Model она не выполняет и в хранилище не пишет.

## Requirements

### Requirement: Попадание возвращает сохранённое значение

Если для этой Model и этих props значение уже есть в хранилище, обращение SHALL возвращает его. Model не выполняется. Новая запись не создаётся.

#### Scenario: Другой запрос получает сохранённое значение

- **WHEN** значение Model уже лежит в хранилище, и другой запрос обращается к той же Model с теми же props со стратегией cache-only
- **THEN** вызывающий получает это значение, Model не выполняется, и хранилище не получает новую запись

### Requirement: Промах не выполняет Model

Если записи нет, обращение SHALL возвращает `undefined`. Model не выполняется. Хранилище не получает запись.

#### Scenario: Записи нет

- **WHEN** для Model и её props записи нет, и вызывающий обращается со стратегией cache-only
- **THEN** результат равен `undefined`, Model не выполняется, и хранилище не получает запись
