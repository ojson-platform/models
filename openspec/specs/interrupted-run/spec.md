# interrupted-run

Прерванный запуск отсутствует в мемоизации запроса и в межзапросном кэше и не записан как успешный span. Вызывающий получает ошибку `InterruptedError`. Значение, которое Model вернула до прерывания, остаётся в мемоизации. Нулевой срок сам запуск не прерывает.

## Requirements

### Requirement: Запуск, прерванный до выполнения Model, не сохраняется как успех

Если запуск уже прерван к моменту обращения, Model не выполняется. Обращение завершается ошибкой `InterruptedError`. Повтор того же обращения в этом запуске снова завершается этой ошибкой, и Model снова не выполняется. Межзапросный кэш запись не создаёт.

Вложенный запуск делит то же состояние прерывания: прерывание внешнего запуска делает обращение из вложенного ошибкой `InterruptedError`.

#### Scenario: Обращение после прерывания не выполняет Model

- **WHEN** запуск прерван, и затем вызывающий обращается к Model
- **THEN** обращение завершается ошибкой `InterruptedError`, и Model не выполняется

#### Scenario: Повтор не находит сохранённый успех

- **WHEN** после такого обращения вызывающий повторяет его в том же запуске
- **THEN** повтор тоже завершается ошибкой `InterruptedError`, и Model не выполняется

#### Scenario: Межзапросный кэш не записывает прерванное обращение

- **WHEN** Model при успехе была бы записана в межзапросный кэш, а запуск прерван до обращения
- **THEN** кэш не получает новую запись, и вызывающий получает ошибку `InterruptedError`

#### Scenario: Вложенный запуск прерывается вместе с внешним

- **WHEN** внешний запуск прерван, и обращение делает вложенный запуск
- **THEN** обращение завершается ошибкой `InterruptedError`, и Model не выполняется

### Requirement: Уже возвращённое значение переживает прерывание

Мемоизация отдаёт значение, которое Model уже вернула, и после того как запуск прерван. Повтор не выполняет Model снова. Прерывание не стирает уже отданную запись.

#### Scenario: Успех до прерывания остаётся в мемоизации

- **WHEN** Model вернула значение, затем запуск прерван, и вызывающий повторяет то же обращение
- **THEN** повтор возвращает то же значение, и Model выполняется один раз

### Requirement: Генератор, прерванный между шагами, не оставляет успех

Если Model отдаёт результат шагами и прерывает запуск между шагами, вызывающий получает `InterruptedError`, а не значение, которое Model собиралась вернуть. Мемоизация не отдаёт это обращение как успех. Межзапросный кэш запись не создаёт.

#### Scenario: Прерывание между шагами

- **WHEN** Model прерывает запуск между шагами
- **THEN** обращение завершается ошибкой `InterruptedError`
- **AND** повтор не возвращает сохранённый успех, и межзапросный кэш запись не создаёт

### Requirement: Истечение срока прерывает ожидание

Положительный срок дожидается значения Model только до таймера. Если таймер наступает раньше, запуск прерван, обращение завершается ошибкой `InterruptedError`, и значение не мемоизируется: повтор Model не выполняет.

Если Model возвращает значение раньше срока, вызывающий получает это значение, и запуск остаётся живым.

Нулевой срок таймер не ставит. Пока вызывающий сам не прервал запуск, запуск живой. После такого прерывания запуск не живой.

#### Scenario: Срок истекает раньше Model

- **WHEN** у запуска положительный срок, и Model не возвращает значение до его истечения
- **THEN** обращение завершается ошибкой `InterruptedError`, запуск не живой, и повтор Model не выполняет

#### Scenario: Model успевает до срока

- **WHEN** Model возвращает значение раньше срока
- **THEN** вызывающий получает это значение, и запуск остаётся живым

#### Scenario: Нулевой срок не прерывает запуск по времени

- **WHEN** срок равен нулю
- **THEN** запуск живой, пока вызывающий сам его не прервёт
- **AND** после этого прерывания запуск не живой

### Requirement: Фоновое обновление кэша скрывает прерывание, обращение вызывающего — нет

Обращение вызывающего, которое завершилось `InterruptedError`, в кэш не пишется, и ошибка доходит до вызывающего.

Фоновое обновление той же записи, если его собственный запуск уже прерван, кэш не пишет и наружу ошибку не отдаёт: обновление завершается без записи.

#### Scenario: Вызывающий видит прерывание, и кэш молчит

- **WHEN** обращение, которое при успехе писало бы кэш, завершается ошибкой `InterruptedError`
- **THEN** кэш запись не создаёт, и вызывающий получает эту ошибку

#### Scenario: Фоновое обновление прерванного запуска не пишет и не падает

- **WHEN** фоновое обновление выполняет Model в запуске, который уже прерван
- **THEN** обновление завершается без ошибки и без новой записи в кэше

### Requirement: Прерванный запуск не сохраняется и не записывается как успех

Прерванный запуск отсутствует в мемоизации запроса и в межзапросном кэше и не записан как успешный span. Вызывающий получает ошибку `InterruptedError`.

Истечение положительного срока — то же прерывание. Ответ совпадает с прерыванием до выполнения Model: ошибка, нет мемоизированного успеха, нет новой записи в кэше, span без события результата.

Если Model прерывает запуск и после этого возвращает значение, это тоже прерванный запуск. Вызывающий не получает это значение. Повтор не отдаёт его как сохранённый успех и Model снова не выполняет. Межзапросный кэш запись не создаёт. Span не получает событие результата.

#### Scenario: Model прерывает запуск и возвращает значение

- **WHEN** Model прерывает запуск и затем возвращает значение
- **THEN** вызывающий получает ошибку `InterruptedError`, и запуск не живой
- **AND** повтор тоже завершается ошибкой `InterruptedError`, Model не выполняется, межзапросный кэш запись не создаёт, и span не получает событие результата

#### Scenario: Истечение срока — то же прерывание

- **WHEN** у запуска положительный срок, и Model не возвращает значение до его истечения
- **THEN** ответ тот же, что у прерывания до выполнения Model: ошибка `InterruptedError`, запуск не живой, повтор Model не выполняет, межзапросный кэш запись не создаёт, и span не получает событие результата

#### Scenario: Прерванный запуск не оставляет успешный span

- **WHEN** запуск прерван до обращения, Model прерывает его между шагами или положительный срок истекает раньше значения, и Model просит записать результат
- **THEN** вызывающий получает ошибку `InterruptedError`
- **AND** span не получает событие результата и не является записью успешного завершения
