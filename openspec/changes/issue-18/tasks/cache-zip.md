# cache-zip

Сценарии этой задачи:

- По умолчанию значение хранится как есть
- Флаг стратегии включает сжатие
- Выключенный флаг стратегии важнее включённого по умолчанию
- Следующая Model наследует чужое сжатие
- Чтение без сжатия не раскрывает запись
- Нераскрываемый текст возвращается как есть
- Не-текст при включённом сжатии возвращается как есть
- Фоновое обновление пишет в выбранной форме

Якорь в `openspec/specs/cache-zip/spec.md` и `design.md`, раздел Technical prerequisites.

## Сделать

Зарегистрировать все восемь сценариев spec id `cache-zip` через `spec`, `requirement`, `scenario`. Заголовки — из `openspec/specs/cache-zip/spec.md`. Где тест уже наблюдает сценарий — сохранить тело, заменить `it` обёрткой в том же коммите. Где теста нет — добавить в существующий spec-файл кэша, не создавая новый файл.

Редактировать только: `src/with-cache/cache-strategy.spec.ts`, `src/with-cache/with-cache.spec.ts`, `src/with-cache/cache.spec.ts`. Продакшен-код, зависимости, vitest и другие spec id не менять.

## Доказательство

Наблюдение: запись и чтение с `zip` и без, приоритет флага стратегии над default, наследование zip в конфигурации, поведение при нераскрываемом тексте и не-текстовом значении, форма записи при фоновом обновлении stale-while-revalidate.

Команды: `pnpm run test:units:fast`, `pnpm run test:types`.
