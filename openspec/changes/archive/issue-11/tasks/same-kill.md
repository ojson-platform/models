# same-kill

Сценарии этой задачи:

- Истечение срока — то же прерывание
- Прерванный запуск не оставляет успешный span

Якорь в `design.md`, раздел Technical prerequisites: `withDeadline` и телеметрия. Рядом пункт «Флага нет» у владельца: отдельного переключателя нет.

`modelIdentity` эта задача не меняет. Depends: #10.

## Сделать

Положительный срок вызывает тот же `kill`, что и вызывающий. `withDeadline(0)` и отрицательный срок по-прежнему возвращают контекст как есть, без таймера. `withDeadline` остаётся шагом композиции и последним в `compose`.

Гонка `resolve` не подставляет возврат `kill` как результат Model. Истечение вызывает `kill`. Значение, которое вернул `kill`, не становится ни результатом `resolve`, ни результатом Model.

Телеметрия спрашивает владельца перед событием `result`. Прерванный запуск события `result` не получает и не записывается как успешное завершение. Так для прерывания до обращения, для прерывания между шагами и для положительного срока. Нового события ошибки нет. Прочая телеметрия не меняется.

Сюда не входит приём значения, которое Model вернула уже после `kill`: вызывающий его ещё получает, мемоизация и кэш этого пути остаются до следующей задачи. `withOverrides` и валидация не меняются.

## Доказательство

Имя каждого теста содержит заголовок своего сценария. Наблюдение — граница `interrupted-run` в `design.md`:

- «Истечение срока — то же прерывание»: положительный срок, Model не вернула значение до него. Ответ тот же, что у прерывания до выполнения Model: `InterruptedError`, запуск не живой, повтор Model не выполняет, `set` кэша нет, события `result` нет. Возврат `kill` вызывающему не отдаётся.
- «Прерванный запуск не оставляет успешный span»: прерывание до обращения, между шагами или по положительному сроку, и Model просит записать результат. Вызывающий получает `InterruptedError`. Span не получает событие `result` и не является записью успешного завершения.

Тест не читает приватное значение прерывания и не требует нового события ошибки. `sign` и `modelIdentity` этим тестом не вызываются.

Команды: `pnpm run test:units:fast`, `pnpm run test:types`.
