# Deepen Model key derivation into one module

## Проблема

Идентичность вызова Model — имя модели и её props — собирается в трёх местах: мемоизация внутри запроса, предустановленное значение и межзапросный кэш. Общего владельца у этого правила нет.

Мемоизация и предустановка отбрасывают `undefined` в props и после этого строят ключ. Кэш строит ключ из props в том виде, в котором их передали. Рядом отдельное построение ключа само пропускает `undefined`. Правка правила в одном месте оставляет остальные прежними, поэтому один и тот же вызов может попасть в один слой и промахнуться в другом.

Model без имени мемоизация и предустановка отвергают. Кэш может собрать для неё ключ.

## Исход

Одно определение идентичности Model. Мемоизация запроса, предустановленное значение и межзапросный кэш спрашивают его.

Вызывающий узнаёт ключ Model и её props одним способом. Отбрасывание `undefined`, включая вложенные props, входит в это определение.

Пока мемоизация, предустановка и кэш уже дают один и тот же текст ключа, текст остаётся прежним: попадания в записи мемоизации и кэша сохраняются. Если тексты уже расходятся, общее определение их выравнивает.

Model без имени не получает идентичность ни в мемоизации, ни в предустановке, ни в кэше.

## Границы

В этом пакете change покрывает:

- идентичность для мемоизации запроса, предустановленного значения и межзапросного кэша;
- одно и то же обращение при пропущенных необязательных props и при вложенном `undefined`.

Вне change:

- углубление прерывания выполнения, которое опирается на этот ключ;
- углубление кэша сверх этой идентичности;
- расширение публичной поверхности хелперов ради доступа тестов к нижнему построению ключа;
- телеметрия, подмена моделей, дедлайн и валидация — своих правил идентичности Model не получают.

Других сервисов change не касается. Дочерние циклы не заводятся.

## Ограничения

- ADR 0006: props остаются `OJson`.
- ADR 0008: ключ детерминирован; мемоизация запроса и межзапросный кэш остаются разными слоями; реестр одного запроса не разделяется с другим запросом.
- Текст существующего ключа стабилен, пока мемоизация, предустановка и кэш уже согласны.
- Наружу остаётся один способ получить ключ Model и её props.
