# interrupted-run

Дельта к baseline. Требования baseline, которых здесь нет, остаются как есть.

Предложение снимает сценарии, в которых прерванный запуск ещё выглядит успехом:

- «Model прерывает запуск и возвращает значение»;
- «Прерывание внутри Model не равно истечению срока»;
- «Телеметрия закрывает прерванный запуск событием результата» и оба его сценария.

Значение, которое Model вернула до прерывания, остаётся в мемоизации, как в baseline. Нулевой срок по-прежнему сам запуск не прерывает.

## Requirements

### Requirement: Прерванный запуск не сохраняется и не записывается как успех

Прерванный запуск отсутствует в мемоизации запроса и в межзапросном кэше и не записан как успешный span. Вызывающий получает ошибку `InterruptedError`.

Истечение положительного срока — то же прерывание. Ответ совпадает с прерыванием до выполнения Model: ошибка, нет мемоизированного успеха, нет новой записи в кэше, span без события результата.

Если Model прерывает запуск и после этого возвращает значение, это тоже прерванный запуск. Вызывающий не получает это значение. Повтор не отдаёт его как сохранённый успех и Model снова не выполняет. Межзапросный кэш запись не создаёт. Span не получает событие результата.

#### Scenario: Model прерывает запуск и возвращает значение

- **WHEN** Model прерывает запуск и затем возвращает значение
- **THEN** вызывающий получает ошибку `InterruptedError`, и запуск не живой
- **AND** повтор тоже завершается ошибкой `InterruptedError`, Model не выполняется, межзапросный кэш запись не создаёт, и span не получает событие результата

#### Scenario: Истечение срока — то же прерывание

- **WHEN** у запуска положительный срок, и Model не возвращает значение до его истечения
- **THEN** ответ тот же, что у прерывания до выполнения Model: ошибка `InterruptedError`, запуск не живой, повтор Model не выполняет, межзапросный кэш запись не создаёт, и span не получает событие результата

#### Scenario: Прерванный запуск не оставляет успешный span

- **WHEN** запуск прерван до обращения, Model прерывает его между шагами или положительный срок истекает раньше значения, и Model просит записать результат
- **THEN** вызывающий получает ошибку `InterruptedError`
- **AND** span не получает событие результата и не является записью успешного завершения
